🎨 Exportador de Diagramas - Espacio de Datos

Diagramas profesionales en alta resolución para presentaciones

📸 Cómo capturar imágenes PNG de alta calidad:

  1. Método Recomendado - Extensión del Navegador:
    • Chrome/Edge: Instala "GoFullPage" o "Nimbus Screenshot"
    • Firefox: Usa "Firefox Screenshots" (integrado)
    • Captura cada diagrama individualmente con la extensión
  2. Método Alternativo - Herramienta Online:
    • Ve a mermaid.live
    • Copia cada código .mmd y pégalo en el editor
    • Usa el botón "Download PNG" o "Download SVG"
  3. Método Script:
    • Ejecuta: cd diagramas-espacio-datos && chmod +x generar-imagenes.sh && ./generar-imagenes.sh
    • Requiere Node.js y npm instalados
💡 Para máxima calidad, usa SVG en lugar de PNG (escalable sin pérdida)
