# Versiones de Tractus-X - iFlex Proof of Concept

**Fecha:** 21 de Mayo de 2026

## Resumen Ejecutivo

Este documento detalla las versiones de los componentes de Eclipse Tractus-X utilizados en el despliegue del proof of concept de iFlex en OVH.

## Versión Principal

**Eclipse Tractus-X EDC: 0.11.1**

## Imágenes Docker en Ejecución

### Control Plane
```
tractusx/edc-controlplane-postgresql-hashicorp-vault:0.11.1
```

**Características:**
- Integración con PostgreSQL para persistencia
- Soporte para HashiCorp Vault para gestión de secretos
- Gestión de negociaciones y contratos
- Endpoints de Management API

### Data Plane
```
tractusx/edc-dataplane-hashicorp-vault:0.11.1
```

**Características:**
- Transferencia efectiva de datos
- Integración con HashiCorp Vault
- Soporte para múltiples protocolos de transferencia
- Gestión de EDR (Endpoint Data References)

## Compatibilidad y Notas

1. **EDC 0.11.1** soporta:
   - Management API v3
   - DSP (Dataspace Protocol) para negociaciones
   - IATP (Identity and Access Token Protocol)
   - Integración con DIM Wallet para gestión de identidad
   - Soporte para BDRS (BPN Discovery Service)

2. **Consideraciones de versión:**
   - La versión 0.11.1 es una versión estable del proyecto Tractus-X
   - Compatible con el ecosistema Catena-X
   - Soporta autenticación mediante OAuth 2.0 y tokens JWT
   - Implementa políticas de acceso basadas en contratos

3. **Actualización:**
   - Para actualizar, modificar la versión en `tx-data-provider/Chart.yaml`
   - Ejecutar `helm dependency update` en el directorio umbrella
   - Redesplegar con `helm upgrade`
